# Automated Network Request Management using ServiceNow

## 📌 Project Overview

Automated Network Request Management is a ServiceNow-based project designed to automate the process of submitting, approving, tracking, and managing network-related requests.

## 🛠️ Technologies Used

- ServiceNow
- Service Catalog
- Flow Designer
- JavaScript
- Client Scripts
- Script Includes
- GlideAjax

## ✨ Key Features

- Network request submission through Service Catalog
- Dynamic user information
- Automated approval workflow
- Email notifications
- Network request record creation
- Request tracking and status updates
